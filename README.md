# CCT Jogos

Primeira versão do PWA da Atlética CCT.

## Para publicar grátis no GitHub Pages
1. Crie uma conta em github.com.
2. Crie um repositório público chamado `cct-jogos`.
3. Envie todos os arquivos desta pasta para o repositório.
4. Vá em Settings > Pages.
5. Em "Build and deployment", selecione "Deploy from a branch".
6. Escolha a branch `main` e a pasta `/ (root)`.
7. Salve e aguarde o link aparecer.

No iPhone:
Safari > Compartilhar > Adicionar à Tela de Início.
