# CCT Jogos — V3 Visual

Protótipo visual da V3 do CCT Jogos.

## Esta versão já demonstra
- Splash screen com mascote
- Home visual com fotos reais
- Menu lateral
- Menu inferior: Início, Jogos, Agenda, Eventos e Perfil
- Competições
- Todos os Jogos / Meus Jogos
- Resultado no próprio card
- Classificação do grupo
- Cenário de classificação
- Agenda de treinos e atendimento na salinha
- Eventos
- Mídia CCT
- Documentos, Locais, Sobre, Parceiros, Contatos e Ajuda
- PWA com manifest e service worker

## Importante
Os dados desta versão são demonstrativos. A próxima etapa é conectar uma base administrativa (Google Sheets / Apps Script) e inserir os dados reais do Interlaje.

## Publicar no GitHub Pages
Substitua os arquivos da raiz do repositório pelos arquivos desta pasta e envie também a pasta `assets`.
